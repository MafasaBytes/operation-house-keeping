# Proposed independently reviewable slices

No slice is authorized for implementation by this package. The owner approved the first-release semantics, not runtime feasibility or ceilings. Each future slice needs its stated evidence and must preserve the checkpoint's maintained thermal/governed behavior. Archived BRC/CP/model-derived work supplies reasoning examples only; no archived implementation is promoted.

| Slice | Application ownership and deliverable | Independent acceptance boundary |
| --- | --- | --- |
| 1: closed contracts and capture | New measurement-specific schema/parser, exact reference resolver, immutable policy and complete required closure. Public model/evidence owners remain authoritative. No selector. | Review frozen shape/diagnostic translation, FR-M1 ordering/collisions and FR-M2 scoped DFS; complete/missing/shared/history and resource refusal controls; no thermal grammar changes. Build witness and exact recoverable environment must be real before runtime acceptance. |

This is not preparation execution. | Execute the owner-approved exact command matrix and harness cases only after proof authorization; independently inspect source-to-cell warrants and runtime traces, measure CPU/wall/RSS/I/O/reserves and every resource boundary. Amendments return to owner. |

Review may stop a slice without requiring later code. A reviewer must not accept self-generated runtime outputs as expected answers. No numerical ceiling can be increased to make a failing case pass without a policy amendment and new exact package. Rebinding to the actual build must preserve oracle tables and source premises with a reviewed dependency diff.

The concrete objective-4 increment is a maintained, replayable answer to which **nominated** procedure conditionally separates the retained hypotheses, including why ranking is withheld. Existing action-cost/thermal results do not answer that question. It establishes neither best measurement globally, truth of a diagnosis, prediction accuracy, authenticated authority nor permission to perform physical measurement.

Owner gate: approve this exact package's wire/CLI/retention/build-binding contract and proposed resource/history policy, or identify precise amendments. Only then separately scope implementation (which slices), runtime proof execution, environment/filesystem qualification and acceptance. Semantic decisions already approved are not reopened by this gate. IN-001 and CI-001 remain open and unselected.
