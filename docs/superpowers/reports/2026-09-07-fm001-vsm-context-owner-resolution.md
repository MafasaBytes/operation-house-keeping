# FM-001 VSM Context Owner Resolution

## 1. Authority

The owner selected Option 2: preserve the existing context-independent
`VariableSemanticDeclaration` contract. FM-001 Slice A resumes; Slice B,
fixtures, demonstrations, appends, and all upper-layer integration remain
unauthorized.

## 2. Resolved discrepancy

The preimplementation discrepancy report identified that the accepted lower
VSM model has no `AssertionContext`. The resolution is to preserve that lower
contract unchanged. The FM support pin proves the exact variable anchor and
the exact measured-actual observation-role token only. It does not compare or
carry FMA context. Exact FMA context is supplied by the FMA subject and must
match the FLD and VPA support pins.

## 3. Exact VSM support

The admitted VSM token is `project_local` /
`ohk-observation-roles-1` / `measured_actual`, with exact variable anchor,
record identity, revision, and declaration dimension `observation_role`.
Wrong variable, dimension, system, edition, code, revision, ID, forged context
extras, or absent VSM remain refusals. The same context-independent VSM may
support FM roots in distinct assertion contexts when all other pins are exact;
this does not retarget or broaden any assertion.

## 4. Documentation correction

The accepted synthesis, ADR-0021, Slice A plan, and final design acceptance
now state this distinction consistently. The historical discrepancy report is
preserved byte-for-byte and is referenced as resolved by this report.

## 5. Scope and compatibility

No VSM migration, contextual wrapper, lower model change, new architecture
layer, durable identity, truth claim, query, fixture, demonstration, ledger
append, or Slice B work is introduced. Existing accepted identities and
history remain valid.

## 6. Slice A authorization

Slice A may implement FMA/FMW contracts, deterministic IDs and canonical
serialization, closure validation and indexes, uncitable withdrawal, and the
specified hostile and replay tests. It must use exact FLD/VPA context equality
and context-independent VSM validation. No Slice B public query or result
surface may be added.

END OF FM-001 VSM CONTEXT OWNER RESOLUTION
