## 2. Root cause and the question the experiment must answer

The frozen control maximum is 22845; primary is 7130. Tested alternatives reached
32553 (typed registry), 24281 (shared material), and 22875 (fully charged capsule).
Shared carriage saves some wire duplication but not the required owning-validator
work. Another wrapper, projection, digest, compression scheme or external store
is not a proposed solution.

The experimental population question is different from carrier engineering:
which semantic witnesses are needed to support the bounded conclusion, rather
than whether every production-shaped combination of independently maximal
dimensions can be admitted together? Structural validity does not imply
operational admissibility under the aggregate node ceiling. Maximal profile
combinations remain evidence and refusal inputs, not mandatory ranked requests
merely because their individual fields are within separate maxima.

The question remains: can bounded minimax rank supplied measurements, and can
existing public contracts derive the H/procedure/conditional-prediction premises
needed to populate it? Mode A answers only the first half. B0/B1/B2 and leakage/
necessity controls answer the second. Neither reducing the A cohort nor reusing
a successful BH result supplies those missing controls automatically.

RC1 remains required for semantic identity/decoder admission; RC2 for compound
gap isolation and population controls; RC3 for executable premise isolation; RC4
for completed-result integrity. NB1 endorses bounded arithmetic, NB2 prevents
edge tests from becoming architectural proof, NB3 treats limits as experimental
ceilings, and NB4 keeps all retained lower evidence synthetic. None is waived.

Mode B/control requests cannot obtain A credit through a parent request, a

for the present epistemic branch basis, not invalid, worthless or deleted.
A profile-stress or closure row can still receive A coverage and may be selected
if it wins the declared optimization. F membership is independently mechanical.
